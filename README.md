# Yusuf Emir Samsa

I build backend systems, production infrastructure, and tools for **safer agent-assisted engineering**.

I'm a Mathematical Engineering student at Istanbul Technical University. I care most about the problems that appear beyond the happy path: resource constraints, failures, authorization boundaries, and how to tell whether a system is actually working.

### What I work on

- **Platforms and reliability:** Operating self-hosted Kubernetes with Argo CD/GitOps, monitoring and alerting, and PostgreSQL backup and point-in-time recovery.
- **Agent tooling:** Building a GitHub App for pull-request review and issue triage, with verified webhooks, bounded automation, and a distinction between model suggestions and trusted delivery evidence.
- **Backend and products:** Building and maintaining commerce and client-facing applications, from data ownership and migrations to deployment and production support.
- **Experiments:** Exploring orchestration for coding agents and human decision-making. The orchestration control plane is a work in progress, not a shipped product.

### How I think about engineering

- **Correctness requires evidence.** Passing tests, CI, and operational checks matter more than a convincing explanation.
- **Autonomy needs boundaries.** Explicit permissions, least privilege, and review gates come before unattended deployment.
- **Failures are part of the design.** Make systems observable, recoverable, and understandable when dependencies fail.
- **Keep the system smaller than the problem.** Reuse mature components rather than rebuilding infrastructure without a reason.
