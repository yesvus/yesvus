I build and operate software, from user-facing products to the systems running behind them. I'm a Mathematical Engineering student at Istanbul Technical University, especially interested in backend engineering, performance, and production reliability.

I prefer understanding *why* something works to simply getting it working. I look for failure modes, operational trade-offs, and opportunities to simplify by adopting tools that already solve the problem.

### Reliable agentic engineering

I use coding agents extensively. But once agents can modify repositories, run commands, and touch infrastructure, the challenge is no longer just generating good code. It's making the entire workflow **safe, recoverable, and verifiable**: scoped permissions, isolated execution, durable state, independent testing and review, and human approval where the consequences demand it.

I want to build systems that let one person coordinate more work without losing visibility, control, or responsibility.
